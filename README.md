# File Organizer

A simple Python tool that automatically organizes files into folders based on their file types.

## Features

- Automatically scans the folder containing the application.
- Groups files by category.
- Creates folders when needed.
- Moves files into their respective folders.
- Supports common file types.

## Download

Download the latest version from the [GitHub Releases](../../releases) page.

Available builds:

- **Windows:** `FileOrganizer-windows.exe`
- **macOS:** `FileOrganizer-macos`
- **Linux:** `FileOrganizer-linux`

## How to Use

1. Download the executable for your operating system.
2. Place it inside the folder you want to organize.
3. Run the executable.
4. Your files will be automatically sorted into folders.

## Important

- The application organizes the folder containing the executable.
- It moves files, so make sure you have backups of important data.
- Test with unimportant files before using it on your main folders.
